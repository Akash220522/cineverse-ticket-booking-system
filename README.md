# 🎬 CineVerse — Movie Booking System

## 📌 Overview

CineVerse is a modern **movie ticket booking web application** that allows users to browse movies, select seats, and simulate payments through an interactive and responsive interface.
The project is built using **HTML, CSS, and JavaScript**, focusing on frontend development and user experience.

---

## 🚀 Features

* 🔐 User Authentication (Login & Signup UI)
* 🎥 Browse Movies (Multi-language support: English, Tamil, Hindi)
* 🔍 Search and Filter Functionality
* 🎟️ Interactive Seat Selection System
* 💰 Dynamic Price Calculation (GST & Convenience Fee)
* 💳 Payment Simulation (UPI / Card / Net Banking)
* 📱 Fully Responsive Design

## ⚙️ Application Flow

1. User logs in or signs up
2. Browse available movies
3. Select a movie, date, and showtime
4. Choose seats dynamically
5. View booking summary and pricing
6. Proceed to payment (simulation)
7. Booking confirmation

---

## 💳 Payment Integration

> ⚠️ Note:
> This project includes **simulated payment functionality only**.
> No real payment gateway is integrated.
